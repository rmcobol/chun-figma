

1. 
컴포넌트 프로퍼티 : 컴포넌트 속성을 관리
종류:
   Variant(베리언트)/Boolean(블린)/Instance swap(스왑 인스턴스)/Text(텍스트) 프로퍼티

2.
베리언트 
 구독하기(컴포넌트:ctrl+alt+k)->우측으로 인스턴스 하나 만든다.
  ->우측 속성->구독하기 Properties + 버튼을 누른다.->Variant을 선택한다.
  ->여기서 + 눌러서 추가로 하나 추가한다.->+ 버튼을 눌러서 추가한다. 총 3개가 만들어 졌다.
  ->첫번째(base)/두번째(배경:빨강/글자:흰색) (hover)/세번째(배경:회색/글자:흰색/테두리:없음) (disabled)
  ->Properites 이름을->state 로 변경
  ->전체 구독하기를 선택해서->우측 속성 Properties +를 선택->Variant 클릭
  ->create property(Name:length/Value:short)->Create property 클릭
  ->세개의 버튼을 선택해 추가 + 버튼을 눌러서 3개를 추가한다.->length의 short의 이름을 long을 변경한다.
  ->세개의 버튼을 늘려준다.->구독하기를 클릭해서 모양을 맞춘다.
  ->인스턴스 내용을 확인 한다.->속성창(state(base-hover-dissabled)/length(short-long)->변경해 본다.

토글
on/off를 추가로 밑으로 하나더 추가 복사한다.
첫번째방법:on(컴포넌트:ctrl+alt+k)/off(컴포넌트:ctrl+alt+k)->on/off 선택후->Combine as variants
두번째방법:컴포넌트가 안된 두개의 on/off 아이콘을 선택->우측 속성 컴포넌트 세부 창을 열면
              ->create component set
둘중아 하나의 방법을 이용하면 됨->on컴포넌트->복사->인스턴스를 하나 만든다.->속성창 Property1에서 클릭해 본다.->토글이 되는지 확인한다.

응용
원 2개를 그린다. 빨강/회색->2개의 원을 선택->컴포넌트(reate component set)->빨강원(on으로 이름 변경)/회색원(off로 이름 변경)
->원 한개를 인스턴스 한다.->인스턴스 원을 선택후 속성창 property 1에서 클릭해 본다->토글이 되는지 확인한다.

3.
 Boolean 
  yes/no-있거나 없거나를 선택하는 것
  채널표시 1 전체 선택->컴포넌트(ctrl+alt+k)->속성창 + 클릭->Boolen 선택
  ->Name(구독버튼)/Value(true)->create properatiy
  ->채널표시 1 선택->속성창 + 클릭->Boolen 선택->
  ->Name(구독자수)/Value(true)->create properatiy
  ->속성창에 에러 표시가 있음
  ->채널표시 1선택->구독버튼 선택->Appearance->두번째(Apply variable/properaty)->구독버튼 선택
  ->채널표시 1선택->20만명 선택->Appearance->두번째(Apply variable/properaty)->구독자수 선택
  ->채널표시 1선택->복사->인스턴스화 한다.
  혹시 속성 토글 키를 눌렀을때 버튼 크기가 줄어들면->가로 크기를 fixed로 고정을 한다.

4. 
Instance swap
 여행 유튜버(컴포넌트:ctrl+alt+k)->우측에 있는 5개 이미지 모두 컴포넌트 한다.(ctrl+alt+k)->여행 유튜버 선택->우측(Properties) + 버튼->Instance swap->Name(유튜브 사진)->value(Component properites(컴퍼넌트 프로퍼티)->곽튜브 선택->Preferred instance Learn more 에서 + 버튼을 클릭->5개의 이미지 선택->Create property
->우측 곽튜브 사진을 복사해서->여행유튜버에 붙여넣기 한다.->기존에 있는 원은 삭제한다.->곽튜브 사진을 연결한다.(Apply instance swap property)->유튜브 사진선택->여행 유튜버를 아래로 이동한다.->여행 유튜브를 인스턴스 해서 위로 복사 한다.->인스턴스 된 것에 사진을 변경한다.->최종 확인 한다.

5. 
Text
Instance swap에서 작업한 부분을 복사해서->text에 붙여 넣기 한다.
->선호하는 여행 유튜버를 선택해주세요(인스턴스 총 5개)->인스턴스ㅁ 스왑에서 밑으로 이동한 여행 유튜버 컴포넌트로 우측 텍스트로 이동한다.
->여행 유튜브 컴포넌트 선택->우측 프로퍼티+에서 ->Text를 선택한다.
Name(유튜버이름)/Value(곽튜브)->create 프로퍼티->여행 유투브 컴포넌트 선택->ctrl+유투버 이름 텍스트 선택->우축 Text->Apply instance swap property 선택 해서 연결한다.
->그럼 전체가 곽투버로 변경된다.->왼쪽 첫번째 인스턴스를 선택해서->우측 유투버사진/유터버 이름을 변경한다.(또떠남/곽투브/빠니보틀/영알남/원지의하루)
